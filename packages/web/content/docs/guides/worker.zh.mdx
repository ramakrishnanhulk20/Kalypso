---
title: 员工
description: "从邀请链接用 Face ID 或钱包加入，查看密封的工资条，并在 Stellar 的练习银行提现。"
---

你的薪水在 [/worker](/worker)。你需要雇主的邀请链接：它是雇主发给你的一个网址，要在手机的浏览器里打开。你还需要一部带通行密钥（Face ID、指纹或设备 PIN）的手机或笔记本电脑，或者设为 Test Net 的 Freighter。Kalypso 的手续费赞助方支付加入和转出薪水的手续费，所以用 Face ID 时没有什么需要充值。Freighter 账户必须已经持有测试 XLM：用 Freighter 的 Fund 按钮。

## 登录

1. 打开邀请链接。顶部有一条标着**邀请**的横条，说明是哪家公司邀请了你：先是公司的名称，然后是“邀请你通过 Kalypso 领取薪水。”
2. 在这台设备上第一次使用时，选择**创建你的薪资密钥**。还没有邀请链接？现在就创建密钥，并把屏幕上的地址发给你的雇主。你的设备会请你确认两次。你的薪资密钥由新的通行密钥在设备上生成，Kalypso 设置好你的钱包，手续费由赞助方支付。处理期间按钮显示“正在等待你的设备，然后设置你的钱包”。
3. 以后回来时，选择**使用 Face ID 登录**（在**已经有薪资密钥了？**下面）。用钱包的话，选择**改用 Stellar 钱包（Freighter）**，再选择**连接 Freighter**，并对 Kalypso 密钥消息签名两次。
4. 等 Kalypso 从链上确认这个钱包是你的之后，页面会在**已登录**下显示你的地址，并带一个复制按钮。在那之前，它显示“钱包尚未设置”。**退出**会让这个标签页忘掉会话，你的通行密钥仍留在设备上。

## 加入公司

5. 选择写着**加入**和你的公司名称的按钮。它的步骤会一项项打勾，从检查邀请到接受邀请，大约一分钟，而且你不用付任何费用。过程中你的设备或 Freighter 会请你批准。
6. 如果你看到“这家公司还没有邀请这个账户。”，卡片上会显示“请你的雇主邀请这个地址：”以及你的地址和一个复制按钮。把地址发给你的雇主。等他们邀请之后，再次选择**加入**按钮。

## 查看你的薪水

7. **你的余额**显示你以 USDC 计的薪水，并带有一行“在链上密封。用你的密钥在这台设备上打开。”每张工资条显示月份和公司、以 USDC 计的金额、一行**支付交易**（附上支付它的那笔交易），以及一行**公司**。
8. 工资条上的“公开可读”标签表示这家公司使用已公布的演示会计密钥，所以任何人都能读到它的金额。“读者未知”标签表示 Kalypso 无法读取这家公司的设置，所以不能判断是否还有别人能读到那笔金额。请重新加载再检查。
9. “历史记录不完整”表示你的历史记录有一部分还没能与链上核对。它下面有一行说明哪里对不上，而显示出来的每一个金额都已通过那项核对。没有工资条且历史记录完整时，页面会显示“还没有工资条。你的雇主发放工资后，它们会出现在这里。”

## 换了新设备之后

Kalypso 在链上找到你的公司，而不只是靠这个浏览器的笔记。你登录之后，它会读取薪酬合约中你的钱包自己的加入事件，只保留链上名单确认你已加入的公司。所以在新设备上，不用再次打开邀请链接，你的工资条就会显示。

只有当 Kalypso 通过从链上读取创建它的那笔交易，确认了你的钱包最初是怎样设置的，你的地址才会显示在**已登录**下。Kalypso 在那之前特意把地址藏起来：知道你通行密钥编号的人，可能已经用自己的代码在那里抢先建了一个钱包，过早显示的地址可能是他们的。与此同时，你的工资条和提现可以正常使用。

在等待期间，一张标着**暂时无法确认你的钱包**的卡片会写着“你的钱包已在网络上，但 Kalypso 还没有确认它最初是怎样设置的，所以它的地址仍然隐藏。下面的工资条和提现仍然可用。”一分钟后选择**再检查一次**。如果 Kalypso 仍然无法确认，这张卡片还会提供**改为创建新的薪资密钥**。新的薪资密钥是一个新的通行密钥和一个新地址，你的雇主必须邀请它，所以只有在你不想等的时候才用。

如果你的钱包还没有上链，卡片的标题是**你的钱包尚未设置**，按钮写着**完成设置**。

## 如果你丢了手机

你已经从 Kalypso 转出的薪水仍然属于你。仍密封在 Kalypso 里的薪水只能用你的通行密钥打开，所以请用 iCloud 钥匙串或 Google 密码管理工具保持同步，并在每个发薪日之后把薪水转出。如果你所有的设备都丢了，请创建一把新的薪资密钥，把新地址发给雇主；以后的薪水会发到那里。

## 提现

10. 在**转到你的提现账户**下，在**金额**框中输入金额，或选择**最大**。页面会复述它读到的内容（“你要转出 1,500.00 USDC。”），按钮写着**转出 1,500.00 USDC**。逗号只算作千位分隔符，小数点用点号，所以“1,5”会被拒绝，而“4,200.50”和“4200.50”都可以。选择这个按钮。你的薪水会以普通 USDC 离开密封余额，只有在页面从链上读到新余额之后，才会显示“已转出。”用 Face ID 时，提现账户来自同一个通行密钥，第一次会免费给它测试 XLM。用 Freighter 时，它就是你自己的钱包账户。你转出的金额是公开的。
11. 在**通过锚点提现**下，选择**打开锚点**。Stellar 的测试锚点是一家练习用的银行：它会在一个小窗口里打开，表单里随便编造的资料都可以，也不会有真钱流动。它的状态显示在按钮下方。
12. 锚点准备好后，一个标着**锚点要求**的框会显示金额，然后是**收款方**、**备注（Memo）**、**锚点手续费**和**你将收到**，全部来自锚点自己的记录。核对金额，然后在五分钟内选择**批准并发送**。最后的状态显示“完成。锚点已付款。”在 testnet 上不会有真钱流动。选择**再次提现**可以开始下一笔。

## 出了问题时

- “这个通行密钥无法生成 Kalypso 密钥，所以没有设置任何内容。Windows Hello 和部分安全密钥暂时还做不到这一点。”当浏览器询问通行密钥要保存在哪里时，请选择 Google 密码管理工具或 iCloud 钥匙串，或者使用你的手机。也可以改用钱包。通行密钥的支持因设备和提供方而异，Kalypso 没有在每一种上检查过。
- “Kalypso 找不到这个通行密钥对应的钱包。如果你是在另一台设备上创建的，请先在那里完成加入。”这个钱包还没有上链，而这个浏览器也没有创建它的记录，所以请到你创建通行密钥的那台设备上完成加入。
- “这个地址在你的钱包设置好之前就被占用了。请创建新的薪资密钥。”或“这个通行密钥不是控制这个钱包的那一个。”别人的钱包占着那个地址，所以 Kalypso 不会使用它。选择**创建新的薪资密钥**，然后请你的雇主邀请新地址。
- 赞助方对每个网络连接每天最多创建三个 Face ID 钱包。超过之后，请用 Freighter，或等一天。
- 加入时，有一条消息以“Kalypso 会先检查链上记录，再重试。”结尾：过一会儿再次选择**加入**，它会跳过已经完成的部分。
- “手续费赞助方目前无法为这次转出付费”会和**自己支付手续费**一起出现。它会转出同样的金额，并从你的提现账户里的测试 XLM 中扣除少量网络手续费。
- “提现服务在你看过之后修改了它的请求，所以没有发送任何内容。请重新发起提现。”请选择**重新开始**。
- 用 Face ID 时，你的钱包只信任创建它的那个通行密钥。如果那个通行密钥在所有设备上都没了，没有人（包括 Kalypso）能找回这笔薪水。

## 你能看到什么，看不到什么

你只能看到自己的工资条和余额，永远看不到同事的薪水或公司的余额。你的雇主和 Kalypso 都看不到你的密钥。任何人都能看到公司付给了你的地址以及付款的时间，还有你转出的金额。锚点能看到你提现了多少。Stellar 的私密代币要求每个账户指定一把能读取其付款的密钥。Kalypso 为你生成一把谁也不持有的密钥：生成它、登记它，并立刻删掉它的私密部分，所以别人无法通过它读到你的薪水。
