title: 会计
description: "登记你的会计密钥，把编号、地址和确认码交给雇主，然后在 /accountant 打开并导出公司的账簿。"
---

[/accountant](/accountant) 的会计端在设为 Test Net 的 Freighter 上运行。你的密钥由你的钱包的两次签名在这个浏览器里生成，所以它不会离开这个浏览器，同一个钱包也总能重新生成它。登记它需要支付一次少量的测试 XLM 手续费，约 0.07，所以你的账户需要先有测试 XLM。下面第一节说明怎么拿到。

## 开始之前

1. 从 [freighter.app](https://www.freighter.app) 安装 Freighter，这是 Stellar 的浏览器钱包。
2. 打开 Freighter，在顶部把网络从 Main Net 切换到 Test Net。
3. 回到 [/accountant](/accountant)，选择**连接 Freighter**。之后只需一键就能领到免费测试币。

连接之后，用**领取免费测试币**卡片领取免费测试币，或者用 Freighter 的 Fund 按钮。测试币是免费的，也没有任何价值。

你先行。在你把会计编号（登记后得到的那个数字）和地址发给雇主之前，雇主无法创建公司。

## 登记你的密钥

1. 打开页面，选择**连接 Freighter**。
2. 在**你的密钥**下，选择**生成我的密钥**。Freighter 会请你对同一条消息签名两次，这证明你的钱包每次都会重新生成同一把密钥。你的**确认码**会出现：16 个字符，分四组。不会发送任何内容。
3. 选择**登记我的密钥**并批准一笔交易。Kalypso 的审计密钥登记表（公开的会计密钥名单）会存下你的密钥，并返回一个新的编号，这就是你的会计编号。只有你，作为它的所有者，能更改这个编号下的密钥。
4. 标着**把这些交给雇主**的框会显示你的**会计编号**和你的**地址**，各带一个复制按钮。把两者都发给雇主。
5. 雇主检查它们时，他们的屏幕会显示一个确认码。把你的念给他们，并确认每个字符都一致。不同的确认码说明他们输入的编号下放的是别人的密钥，他们必须停下。

## 打开账簿

6. 在**打开一家公司的账簿**下，输入雇主给你的**公司编号**，然后选择**打开账簿**。如果你还没有在这个页面上给出那两次密钥签名，Freighter 会请你签。Kalypso 会先向登记表确认你的密钥持有这家公司薪酬所密封到的那个编号。
7. 卡片会随着你的浏览器读取薪酬历史、用你的密钥打开每笔付款而逐步填满。每一行显示批次、员工、交易和金额，每个批次有一个小计，有两个或更多批次时还有一个合计。只有链上计数的每个批次和每笔付款都已找到并核对时，标签才会显示“已验证完整”。否则它显示“历史记录不完整”。
8. 选择**导出 CSV**。一个以公司编号和今天日期命名的文件会保存到你的电脑上，每笔付款一行：批次编号、期间、员工、以 USDC 计的金额和交易哈希。Kalypso 拒绝导出不完整的账簿，所以文件绝不会在不完整时看起来像整份薪酬。表格软件会当作公式执行的单元格，会先被处理成无害的。

想在真实公司指定你之前先试试？演示公司的密钥公开在[首页](/#lens)，密钥透镜会在那里打开它的账簿。

## 出了问题时

- “这家公司的账簿密封给了一个会计编号，而这个钱包的密钥不持有该编号，所以无法用它打开。”请连接你登记时用的那个钱包。如果已经是那个钱包，说明这家公司是用另一位会计的编号设立的。
- “薪酬合约上不存在这个编号的公司。”请向雇主核对编号。
- “这个钱包的账户在 testnet 上还不存在。”请用**领取免费测试币**卡片，或 Freighter 的 Fund 按钮，领取免费测试 XLM，然后再登记。
- “账簿不完整，所以没有导出任何内容。”后面还会跟着原因。请一分钟后重试，因为最新的账本可能还没读到。
- “Freighter 没有签名，所以没有发送任何内容。”你拒绝了一个提示。请再次选择那个按钮。
- “请把 Freighter 切换到 Testnet，然后重试。”Kalypso 只运行在 Stellar testnet 上。

## 你能看到什么，看不到什么

你能看到每一家公司付出的每一笔金额，只要它的薪水密封到你的编号上。按设计，你的密钥也能打开每笔付款之后金库的余额，不过这个界面只列出付款。你的密钥只能读：它动不了任何资金。你读不到员工自己的余额，因为每位员工都登记了自己的审计密钥。谁能读到一家公司的薪水，是根据登记表里它那个编号当前的所有者来读的，而不是根据公司创建时记录的会计。

如果你的密钥泄露了，谁拿到它，谁就能读到曾经密封给它的一切。登记表只允许你自己替换它，通过它的 `rotate_key` 调用，而这个界面不提供这个功能。新密钥只保护之后的付款。
