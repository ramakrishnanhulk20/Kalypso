You need Git, Node.js 24 (the server needs 24; the testnet scripts need 22.9 or later), a Rust toolchain for the contracts (CI uses Rust 1.99.0), and the [stellar CLI](https://github.com/stellar/stellar-cli) 28.1.0 for the build attestation check.

```bash
git clone https://github.com/ramakrishnanhulk20/Kalypso.git
cd Kalypso
```

Each command block below starts from the repo root.

## Check the stack from chain state

`check:testnet` reads chain state and runs 18 checks: nobody, including us, can change which proofs the verifier accepts; neither of our contracts has an admin or an upgrade path; the code on chain is the released code; and every contract has at least 14 days before it archives. It needs the payroll from release v0.1.1 and the auditor registry from release v0.1.0, each in its own folder:

```bash
mkdir -p release/v0.1.1 release/v0.1.0
curl -fL -o release/v0.1.1/kalypso_payroll.wasm https://github.com/ramakrishnanhulk20/Kalypso/releases/download/v0.1.1/kalypso_payroll.wasm
curl -fL -o release/v0.1.0/kalypso_auditor.wasm https://github.com/ramakrishnanhulk20/Kalypso/releases/download/v0.1.0/kalypso_auditor.wasm
cd packages/contracts/scripts && npm ci
npm run check:testnet -- --wasm-dir ../../../release/v0.1.1 --auditor-wasm-dir ../../../release/v0.1.0
```

The same files are on the [Releases page](https://github.com/ramakrishnanhulk20/Kalypso/releases). A passing run ends with `18 of 18 checks passed. RESULT: PASS`.

## Attack the showcase

`prove:testnet` attacks the showcase company's promises on testnet and prints what stopped each attack. It runs 13 checks and needs no keys.

```bash
cd packages/core && npm ci && npm run build
cd ../contracts/scripts && npm ci && npm run prove:testnet -- --archive https://kalypso-payroll.vercel.app/api/archive/
```

Without the seed's private file, the amounts are checked with the published demo accountant key and the worker half of P10 is skipped, so a stranger's run ends with 12 passed and 1 skipped. The history checks read RPC, which keeps about the last 7 days. The `--archive` flag above reads older ledgers from Kalypso's live event archive, so the history checks keep working after that window; its health is public at [/api/archive/v1/health](https://kalypso-payroll.vercel.app/api/archive/v1/health). The last full run is on [Attack run](/docs/security/attack-run).

## Keep the stack alive

```bash
cd packages/contracts/scripts && npm ci && npm run keepalive:testnet
```

This extends the storage life of all four contracts and their code, 60 days by default (`-- --days <n>` to change it), so none archives while you and other visitors are looking at it. Anyone may pay for an extension and it changes nothing else. It pays from the stellar CLI identity named by `DEPLOYER` (default `kalypso-deployer`) in `packages/contracts/.stellar`, which must exist and hold testnet XLM. `check:testnet` fails once any contract has fewer than 14 days left.
