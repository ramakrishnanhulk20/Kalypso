Kalypso 的名字取自希腊语的 Kalypso（Καλυψώ），意为“隐藏者”。

Kalypso 是 Stellar 上的薪酬发放：除了该看的人，没有人能读到薪水。公司用 USDC 给团队发薪。公开账本显示每笔付款发生过，但从不显示金额。每位员工只读到自己的薪水，公司的会计则持有一把密钥，能读到公司付出的每一笔金额。

它建立在 OpenZeppelin 为 Stellar 做的机密代币之上，Stellar 开发基金会（SDF）把它列为适用于薪酬发放的方案。Kalypso 在此之上增加了一份薪酬合约、一个审计密钥登记表，以及一个在浏览器里为每笔付款生成证明的客户端库。三个界面把它投入使用：雇主用电子表格发薪，每位员工用 Face ID 或钱包加入并在锚点提现，会计打开并导出账簿。它目前运行在 Stellar testnet 上。

## 为谁而做

任何用 USDC 给远程团队发薪的公司。在公共链上用普通 USDC 付款，任何有区块浏览器的人都能看到金额，所以这样发出的每份薪水都是公开的。Kalypso 让付款留在链上，金额保持密封，会计仍然能读账簿。

## 三把密钥

| 密钥 | 持有者 | 能打开什么 |
|---|---|---|
| 金库密钥 | 雇主 | 动用公司的资金，并读取金库自己的余额。薪酬合约每个批次对每位员工最多付一次，而且只凭这把密钥的签名。 |
| 员工密钥 | 每位员工，仅本人 | 该员工自己的工资条和余额。薪酬里的其他内容一概打不开。 |
| 会计密钥 | 公司的会计 | 公司付出的每一笔金额，以及每笔付款之后金库的余额。它不能动用资金。 |

会计在 Kalypso 的审计密钥登记表里登记自己的密钥，也只有他们能更改它。Kalypso 持有的任何密钥都不能读取真实公司的薪水，也不能动用它的资金。

## 哪些保持私密，哪些不是

私密的：每一笔薪水金额和每一份余额。

按设计公开的：

- 谁付给谁，什么时候付。每家公司的员工名单都在链上，所以员工人数也是公开的。
- 存入和转出的金额。为金库充值的那笔存款大致显示了薪酬的成本，而恰好转出一笔薪水的员工，会暴露这笔薪水。
- 会计能看到公司付出的每一笔金额。这正是他们那把密钥的用途。

没有防御的：

- 泄露的密钥能打开一切曾加密给它的内容。轮换密钥只保护以后的付款。
- 合约无法知道一个隐藏的金额是不是正确的薪水。每笔付款之后，Kalypso 的发薪引擎会检查离开金库的恰好是获批的金额，所以错误的金额是事后被发现，而不是事先被阻止。
- 被入侵的钱包扩展或电脑、在钓鱼网站上签下 Kalypso 密钥消息的用户，以及 USDC 发行方冻结汇集的资金。
- OpenZeppelin 的机密代币、它的电路或它的验证器中的缺陷，这些都是新的，也未经审计。

Kalypso 仅限 testnet，未经安全公司审计。[安全页面](/docs/security/overview)说明了它是如何被检查的，以及你怎样自己检查。
